# MNT-04 版本与交付物可追溯

| 项 | 内容 |
|---|---|
| 类型 | 可维护性 |
| 证据 | EV-05（B 级） |
| 优先级 | P2 |
| 关联 | Q1 |
| Issue | #4 |


## 1 现象

测试记录中同时出现三种版本写法：`stable` 标签"未核实版本"、容器日志 `Memos 0.31.0`、
报告正文 `v0.31.0`；部署形态也有 Docker 与 Windows 原生两种，数据库互不相通。

## 2 影响

"同一环境"的前提不成立，跨报告的数据证据无法互证；换人复现时无法确认装的是哪个版本。

## 3 期望

任何人拿到报告，都能复现到同一版本；所有记录引用同一张基线卡。

## 4 方案

- 出《环境与基线卡 B-01》，固定版本、digest、数据目录、端口、账号；
- `docker-compose.yml` 用 digest 固定镜像（`image: neosmemo/memos@sha256:...`），不用 `:stable`；
- 启动脚本打印版本与 digest 写进日志；
- 报告每章开头引用卡号。

## 5 代价与风险

约 0.5 人日。风险：固定 digest 后升级需手动改，脚本里加"检查新版本"提示即可。

## 6 验收

- [ ] 基线卡已出，`docker inspect` 结果与卡一致；
- [ ] 报告各章引用同一卡号；
- [ ] 换机器按卡能复现。
