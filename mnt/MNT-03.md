# MNT-03 超长标签不撑破页面

| 项 | 内容 |
|---|---|
| 类型 | UI 缺陷 |
| 证据 | EV-02、EV-03（A/B 级） |
| 优先级 | P2 |
| 关联 | C-03 |
| Issue | #4 |


## 1 现象

连续输入 300 个 `a` 或 1000 个 `b` 作为标签并保存，笔记详情页出现横向滚动条：
页面宽度 1422 px，滚动宽度 2955 px（300 字符）/ 9764 px（1000 字符），刷新后仍复现。
同一长度中文标签正常换行，不溢出。

## 2 影响

桌面端阅读含长标签的笔记需要横向拖动；移动端整页被撑宽，按钮移出屏幕，属于显示缺陷，
不影响保存与数据完整性。

## 3 期望

任意长度的中英文标签都不产生横向滚动，标签在卡片内省略或换行，悬停或点开可查看全文。

## 4 方案

- 标签元素：`max-width: 12rem; overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`
- 父容器补 `min-width: 0`（flex 子项不收缩是溢出的常见根因）；
- 悬停用 `title` 或 tooltip 显示全文；
- 移动端断点单独调一次。

## 5 代价与风险

约 0.5 人日（含回归）。风险：`max-width` 用上限值而非固定宽度，避免短标签被拉宽。

## 6 验收

- [ ] 300 / 1000 字符英文标签，`scrollWidth == clientWidth`；
- [ ] 中文长标签、普通标签不回归；
- [ ] 折叠态可查看全文。
