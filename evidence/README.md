# 证据目录

## 命名

`EV-编号-一句话描述.png`，例如 `EV-01-并发落库两条重复记录.png`。

## 规则

1. 正文只引编号（"见 EV-01"），不引"图 3"——图号每改一版就乱，编号不会；
2. 截图三要素：能看到页面或命令、能看到结果、能看到时间或账号；
3. 提交前脱敏：内网 IP、分享 Token、账号口令替换为 `<HOST>` `<TOKEN>` `<ACCOUNT>`。
