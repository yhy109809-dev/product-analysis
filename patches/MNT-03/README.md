# MNT-03 补丁说明：限制标签最大宽度

## 目标

任意长度的中英文标签都不产生横向滚动（`scrollWidth == clientWidth`）。

## 现状

- 300 字符英文标签：页面 1422 px，滚动宽度 2955 px；
- 1000 字符英文标签：滚动宽度 9764 px，刷新后仍复现；
- 同长度中文标签正常换行，不溢出。

## 待定位

需要在 `web/src` 中找到渲染标签的组件，确认具体文件与行号后，把
`tag-overflow.css` 中的规则落到该组件的样式里（或对应的 Tailwind 类）。

> 定位结果回填到本文件，并把本 PR 从 Draft 转为 Ready。

## 改动要点

1. 标签元素加 `max-width` + 省略号，避免连续英文撑开卡片；
2. 父容器补 `min-width: 0`——flex 子项默认不收缩，是溢出的常见根因；
3. 悬停用 `title` 显示全文，信息不丢。

## 验收

- [ ] 300 / 1000 字符英文标签 `scrollWidth == clientWidth`；
- [ ] 中文长标签、普通标签不回归；
- [ ] 折叠态可查看全文；
- [ ] 移动端断点下不溢出。
