# 04 评测找问题

## 4.1 方法与口径

- **证据等级**：A 级＝代码位置与运行结果双证；B 级＝单一运行证据（抓包、截图、日志、数据库）；C 级＝仅界面观察或文档引用。
- **判定标签**（五选一）：`功能正常` / `确认Bug` / `功能缺失` / `查明是环境原因` / `受限无法测试`。
- **结论句式**：在〈基线卡编号〉环境下，执行〈步骤〉，得到〈结果〉，判定为〈标签〉，证据 EV-xx。

### 4.2.1 苏：CI 与测试覆盖核对

**官方配置**：后端工作流包含代码检查与 store、server、internal、other 四组测试；前端工作流包含代码检查、单元测试与构建。此外还有协议检查与发布前冒烟（见第 3 章）。

**源码抽查**（v0.31.0）：

| 关注点 | 位置 | 测了什么 | 与本组结论的关系 |
|---|---|---|---|
| 删除 | `store/test/memo_test.go`（TestMemoStore、TestDeleteMemoStore） | 创建、修改、查询、删除，并检查删除后列表为空 | 证明"能删"，不涉及"能否恢复" |
| 私密笔记权限 | `core/access/memo_test.go`、`server/api/v1/test/memo_service_test.go` | 作者可读自己的私密笔记，他人被拒；跨账号请求返回 PermissionDenied | 与 C-05 一致 |
| 导出 / 导入 | `server/api/v1/test/memo_export_test.go` | 附件名称、路径、大小、内容；导入冲突处理 | 与 C-04 一致 |
| 草稿缓存 | `web/tests/memo-editor-cache.test.ts` | 草稿保存与重新读取 | 未覆盖"断网保存后刷新"完整链路 |
| 标签识别 | `markdown/markdown_test.go`（TestExtractTags） | 标签解析 | 属服务端解析，不覆盖浏览器端宽度与换行 |
| 幂等 | 未找到相关用例 | — | 与本组并发发现相互印证 |

**近期 Actions 运行**：列表中有成功记录（#5978，main 分支提交，绿色对勾），也有失败记录（#5977，由 PR #6513 触发，红叉）。查看 #5977 详情，总时长 41 分 12 秒，页面说明为
"This workflow run required approval but was not approved before it expired."——即该次运行需要审批、过期前未获批准，页面没有提供测试执行失败的证据。

**判定**：官方确实配置了自动化检查，也确实编写了删除、权限、导出附件、草稿与标签相关测试；但覆盖集中在后端与解析层，"浏览器断网后保存并刷新""双击只发一次请求"这类界面层完整操作没有对应测试。本组的实测与官方测试是互补关系，不是互相否定。

**限制**（苏已自行声明，照录）：本次核对的是近期分支运行情况，不等于 v0.31.0 标签的运行结果；未取得覆盖率数字。两者不能互相替代。
